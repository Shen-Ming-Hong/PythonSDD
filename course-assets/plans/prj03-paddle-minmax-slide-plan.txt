課程名稱：prj03_paddle.py｜Paddle 移動邊界與 min/max
來源：Day1/prj03_paddle.py（以目前檔案的 raw line number 為準）
目標對象：Python／Pygame 入門學生
溝通任務：讓學生看懂 Paddle 的左邊座標為什麼只能落在 0～680，以及第 54 行如何用 min() 與 max() 將每次移動後的位置夾回安全範圍。
核心結論：`rect.x` 是底板左邊的位置；右邊界要先扣掉底板寬度，所以 `WIDTH - self.rect.width = 800 - 120 = 680`，再用 `max(0, min(...))` 同時守住左右兩側。
敘事弧線：看見出界問題 → 讀懂座標與物件寬度 → 推導 680 → 拆解 min/max → 對照原始程式 → 用例子驗證 → 推廣到不同寬度。
視覺方向：16:9 橫式、滿版教學圖卡；淺色紙張／教室資訊圖風格，深藍座標與程式碼、珊瑚紅出界警示、薄荷綠安全區、圓潤可愛教學機器人；每頁一個主畫面，文字少而大，程式碼頁使用白底亮色 editor。
外部來源：無；所有程式與數字均取自 Day1/prj03_paddle.py。

=== Code Block P03-54 ===
```diff
  38 class Paddle:
  39     """Paddle 負責讀取方向並守住畫面邊界。"""
  40
  41     def __init__(self):
  42         self.rect = pygame.Rect(0, 0, 120, 16)
  43         self.rect.midbottom = (WIDTH // 2, HEIGHT - 34)
  44         self.speed = 8
  45
  46     def update(self, keys):
  47         direction = 0
  48         if keys[pygame.K_LEFT] or keys[pygame.K_a]:
  49             direction -= 1
  50         if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
  51             direction += 1
  52
  53         self.rect.x += direction * self.speed
  54         self.rect.x = max(0, min(self.rect.x, WIDTH - self.rect.width))
```
