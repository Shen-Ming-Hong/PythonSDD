# 規格：公開網頁版敲磚塊遊戲

**功能分支**：`002-web-game-publish`

**建立日期**：2026-08-28

**狀態**：已完成，已公開發佈

**輸入**：使用者描述：將現有敲磚塊遊戲製作成可在瀏覽器直接遊玩的公開網頁版本；保留桌面教學版本並存，第一版支援桌面鍵盤，並使用 Sites 公開發佈。

## 使用者情境與測試

### 使用者故事 1－從公開網址開始遊戲（優先級：P1）

訪客開啟公開網址後，不需要登入或安裝桌面程式，就能看到完整的敲磚塊版面並開始遊玩。

**優先級理由**：可直接進入並操作遊戲是網頁版本的核心價值，也是公開發佈是否成功的第一個判斷條件。

**獨立測試**：在未登入的桌面瀏覽器開啟公開網址，確認遊戲版面與初始狀態出現，再用鍵盤發球、移動底板並完成至少一次磚塊碰撞。

**驗收情境**：

1. **假設**訪客首次開啟公開網址，**當**頁面完成載入，**則**可看到遊戲版面、45 塊磚、`Lives: 3` 與 `Score: 0`，且不要求登入或安裝其他程式。
2. **假設**遊戲正在等待發球，**當**玩家按下 Space，**則**球開始移動並進入遊戲進行狀態。
3. **假設**遊戲正在進行，**當**玩家按住 Left／Right 或 A／D，**則**底板在遊戲左右邊界內移動，放開按鍵後不再持續加速。
4. **假設**球碰到牆面、底板或仍存在的磚塊，**當**碰撞發生，**則**球依既有規則反彈；磚塊碰撞只移除該磚一次並增加 10 分。

### 使用者故事 2－完成或結束一局並重新開始（優先級：P1）

玩家清除所有磚塊或耗盡生命後，能清楚知道回合結果；在結果畫面可以開始全新的回合。

**優先級理由**：完整的勝利、失敗與重玩流程才能讓遊戲成為可完成的體驗，而不是只能展示初始畫面。

**獨立測試**：分別完成一次清板與一次生命耗盡，確認兩種結果互斥且畫面凍結，再按 Space 驗證每次都完整恢復初始回合。

**驗收情境**：

1. **假設**回合尚有磚塊，**當**玩家擊破最後一塊磚，**則**完成最後一次 10 分計分，顯示 `You Win` 與 `Press SPACE to restart`，並保留最終分數與生命數。
2. **假設**勝利或 Game Over 畫面已顯示，**當**玩家等待、按方向鍵或按 A／D，**則**球、底板、磚塊、分數與生命數都維持不變。
3. **假設**回合尚有磚塊且玩家耗盡三次生命，**則**顯示 Game Over 而不是 You Win，並保留當局結果。
4. **假設**勝利或 Game Over 畫面已顯示，**當**玩家按下 Space，**則**恢復 45 塊磚、`Lives: 3`、`Score: 0`、置中的底板與等待發球的球。

### 使用者故事 3－公開發佈並驗證可用性（優先級：P2）

發布者在本機人工測試通過後，能將網頁版本公開發佈；訪客拿到網址即可直接載入並遊玩，不需要依賴發布者的電腦環境。

**優先級理由**：公開網址是本功能相對於既有桌面版本的交付成果，但必須建立在遊戲功能已完成且通過人工測試之後。

**獨立測試**：使用已通過前兩個故事驗收的網站版本完成公開部署，再從未登入的新瀏覽器視窗開啟網址，確認頁面能載入並完成初始狀態、鍵盤操作與重玩最小檢查。

**驗收情境**：

1. **假設**網站版本已完成建置並通過本機人工測試，**當**發布者執行公開發佈，**則**產生可分享的公開網址，且不要求訪客登入。
2. **假設**訪客在未登入的新瀏覽器視窗開啟公開網址，**當**頁面完成載入，**則**可看到遊戲入口、45 塊磚、`Lives: 3` 與 `Score: 0`，不需要本機 Python、Pygame 或開發伺服器。
3. **假設**訪客已從公開網址進入，**當**依序執行發球、底板移動與終止狀態重玩最小檢查，**則**公開版本的行為與本機驗收版本一致。

### 邊界情況

- 最後一塊磚的 10 分必須先計入，再顯示勝利結果；同一塊磚不得重複計分。
- 球遺失但版面仍有磚塊時，只扣除一條生命並將球放回底板上等待發球；生命歸零時必須顯示 Game Over。
- You Win 與 Game Over 必須互斥；終止畫面不得因時間經過或非重置按鍵改變狀態。
- 在終止畫面重複按 Space 不得增加生命、分數或磚塊；重新開始後才允許再次發球。
- 瀏覽器視窗縮小時，遊戲區仍須完整可見且不應因版面被截斷而無法操作；第一版不承諾觸控操作。
- Space 用於遊戲操作時不得造成頁面意外捲動；重新整理頁面視為開始新回合，不恢復前一局資料。

## 需求

### 功能需求

- **FR-001**：公開網址 MUST 讓未登入訪客直接進入可遊玩的敲磚塊遊戲，不得要求安裝桌面程式。
- **FR-002**：每個新回合 MUST 從 45 塊存活磚塊、3 次生命與 0 分開始。
- **FR-003**：玩家 MUST 能使用 Space 發球，並使用 Left／Right 或 A／D 在左右邊界內控制底板。
- **FR-004**：遊戲 MUST 保留牆面反彈、底板反彈、磚塊碰撞、每塊磚 10 分與球遺失扣生命的既有規則。
- **FR-005**：球遺失且仍有剩餘生命時，遊戲 MUST 扣除一條生命並讓玩家重新發球；生命歸零且仍有磚塊時 MUST 進入 Game Over。
- **FR-006**：最後一塊磚被擊破並完成計分後，遊戲 MUST 進入勝利狀態並顯示 `You Win`。
- **FR-007**：勝利與 Game Over 狀態 MUST 顯示 `Press SPACE to restart`，並保留當局的最終分數與生命數。
- **FR-008**：進入勝利或 Game Over 後，遊戲 MUST 停止球、底板、磚塊與碰撞的持續更新，直到玩家重置或重新整理頁面。
- **FR-009**：玩家在任一終止狀態按下 Space 時，遊戲 MUST 完整重置磚塊、生命、分數、球、底板與終止狀態。
- **FR-010**：遊戲頁面 MUST 在常見桌面瀏覽器視窗中保持遊戲區完整可見，且不以觸控支援作為第一版必要條件。
- **FR-011**：本功能 MUST 保留既有桌面教學檢查點的獨立執行能力，不得以網頁版本取代或刪除原有檔案。

### 主要實體

- **遊戲回合**：代表從初始狀態開始，直到勝利、Game Over 或重新整理頁面的一局，包含分數、生命、磚塊、球與底板狀態。
- **磚塊**：版面上的單一可破壞目標，每塊磚只能存活、被擊破並計分一次。
- **玩家控制**：代表鍵盤輸入與底板位置；只在遊戲進行中影響底板。
- **終止結果**：代表勝利或 Game Over 的互斥結果，出現後保留回合畫面直到 Space 重置。
- **公開遊戲頁面**：訪客可透過公開網址直接開啟的單一遊戲入口。

## 成功標準

### 可量測結果

- **SC-001**：在 3 次彼此獨立的未登入開啟測試中，公開網址每次都能顯示可遊玩版面、45 塊磚、3 次生命與 0 分，不需安裝桌面程式。
- **SC-002**：在 3 次獨立的操作測試中，玩家每次都能使用 Space 發球、使用 Left／Right 或 A／D 移動底板，並完成至少一次磚塊碰撞與 10 分計分。
- **SC-003**：在 3 次獨立的完整清板測試中，最後一塊磚消失後 1 秒內都顯示 You Win 與重新開始提示，且最後一次計分已包含在最終分數中。
- **SC-004**：在 3 次獨立的失敗測試中，玩家於尚有磚塊時耗盡三次生命，每次都顯示 Game Over 而非 You Win，且結果畫面可維持 10 秒不變。
- **SC-005**：在 3 次獨立的勝利或失敗重玩測試中，按下 Space 後每次都恢復 45 塊磚、`Lives: 3`、`Score: 0` 與等待發球狀態。
- **SC-006**：在至少 3 種桌面瀏覽器視窗尺寸下，遊戲區都能完整看見、沒有被截斷，且主要鍵盤操作仍可完成。
- **SC-007**：由 5 位第一次接觸網頁版本的玩家各自觀看結果畫面，至少 4 位能指出目前是勝利或 Game Over，並找出使用 Space 重玩的方式。

## 假設

- 主要使用者是使用桌面鍵盤的訪客；手機觸控、行動版專用操作與遊戲手把不在第一版範圍內。
- 網頁版與現有桌面教學版本並存；桌面版本保留作為教學與既有規則的參考，網頁版提供公開遊玩入口。
- 網頁版是一個不需登入的單頁遊戲，不保存玩家分數、生命、回合或個人資料。
- 第一版不包含音效、特效、特殊磚塊、多關卡、排行榜、分享成績、後端服務或自訂網域。
- 訪客具有可正常載入公開網址的網路連線與支援鍵盤輸入的現代桌面瀏覽器。
- 公開發佈後以拿到網址的訪客可直接遊玩為驗收目標；正式部署前仍需完成建置與人工測試。
