# 資料模型：公開網頁版敲磚塊遊戲

**功能規格**：[spec.md](./spec.md)

## 遊戲回合

代表從新回合建立開始，直到勝利、Game Over 或重新整理頁面的一局。

| 欄位 | 型別 | 意義 | 規則 |
|------|------|------|------|
| `score` | number | 擊破磚塊所得分數 | 初始為 0；每擊破一塊磚增加 10；終止狀態下維持不變。 |
| `lives` | number | 剩餘生命次數 | 初始為 3；球遺失時減少；尚有磚塊且降至 0 時進入 Game Over。 |
| `gameOver` | boolean | 是否因生命耗盡而結束 | 初始為 false；只在尚有磚塊且最後一次生命遺失時為 true。 |
| `gameWon` | boolean | 是否因清空版面而結束 | 初始為 false；最後一塊磚被摧毀並計分後為 true。 |
| `bricks` | Brick[] | 目前版面上的磚塊 | 每個新回合包含 45 塊存活磚；沒有存活磚時才能勝利。 |
| `paddle` | Paddle | 玩家控制的底板 | 只在回合進行中更新；重置時回到水平置中。 |
| `ball` | Ball | 球的位置、速度與發球狀態 | 等待發球時跟隨底板；回合進行中更新與碰撞；重置時回到底板上方。 |

## 磚塊（Brick）

| 欄位 | 型別 | 意義 | 規則 |
|------|------|------|------|
| `x`、`y` | number | 磚塊左上角位置 | 使用 800×600 邏輯遊戲座標。 |
| `width`、`height` | number | 磚塊大小 | 維持既有 72×24 尺寸與 8 像素間隔。 |
| `color` | string／color | 顯示顏色 | 依所在列使用既有五色。 |
| `alive` | boolean | 是否仍存在 | 初始為 true；被擊中後只變為 false 一次。 |

## 底板（Paddle）

| 欄位 | 型別 | 意義 | 規則 |
|------|------|------|------|
| `x`、`y` | number | 底板位置 | 初始水平置中，垂直位置維持既有遊戲區下方位置。 |
| `width`、`height` | number | 底板大小 | 維持 120×16。 |
| `speed` | number | 以 60 FPS 為基準的水平速度 | 只在遊戲進行中依輸入移動，並限制在 0 至遊戲寬度內。 |

## 球（Ball）

| 欄位 | 型別 | 意義 | 規則 |
|------|------|------|------|
| `x`、`y` | number | 球心位置 | 以遊戲邏輯座標表示；等待發球時位於底板上方。 |
| `radius` | number | 球半徑 | 維持既有 9。 |
| `velocityX`、`velocityY` | number | 以 60 FPS 為基準的速度 | 碰到左右牆反轉 X；碰到上牆、底板或磚塊依既有規則反轉對應方向。 |
| `launched` | boolean | 是否已發球 | 新回合與球遺失後為 false；Space 發球後為 true。 |

## 玩家輸入

輸入不是持久化資料；頁面入口將鍵盤事件轉換為以下概念事件：

| 事件 | 作用 | 有效狀態 |
|------|------|----------|
| `launch` | 讓等待中的球開始移動 | 進行中且球尚未發出 |
| `moveLeft` | 底板向左移動 | 進行中 |
| `moveRight` | 底板向右移動 | 進行中 |
| `restart` | 呼叫完整重置 | 勝利或 Game Over |

## 狀態轉換

| 目前狀態 | 事件 | 條件 | 下一狀態 | 效果 |
|----------|------|------|----------|------|
| 進行中（Active） | Space | 球等待發球 | 進行中（Active） | 球開始依速度移動。 |
| 進行中（Active） | 磚塊碰撞 | 尚有至少兩塊存活磚 | 進行中（Active） | 該磚塊變為不存活、分數增加 10、球反彈。 |
| 進行中（Active） | 磚塊碰撞 | 這是最後一塊存活磚 | 勝利（Won） | 完成移除與 10 分計分、保留畫面並停止更新。 |
| 進行中（Active） | 球遺失 | `lives > 1` | 進行中（Active） | 生命減少、球重置到板上並等待發球。 |
| 進行中（Active） | 球遺失 | `lives == 1` 且仍有磚 | Game Over | 生命設為 0、保留版面並停止更新。 |
| 勝利（Won） | Space | 一律成立 | 進行中（Active） | 重建 45 塊磚、底板與球，分數與生命重置。 |
| Game Over | Space | 一律成立 | 進行中（Active） | 重建 45 塊磚、底板與球，分數與生命重置。 |
| 勝利／Game Over | 其他輸入或經過時間 | 一律成立 | 相同終止狀態 | 不改變回合資料；Escape 不關閉瀏覽器。 |

## 不變條件

- `gameWon` 與 `gameOver` 在同一回合不得同時為 true。
- 只有全部 45 塊磚的 `alive` 都為 false 時，`gameWon` 才能為 true。
- 每塊磚最多產生一次 10 分計分增加。
- 終止狀態在 Space 重置前不會改變分數、生命、磚塊、球或底板。
- 重置一定恢復 45 塊存活磚、3 次生命、0 分、置中的底板，以及連接在底板上方等待發球的球。
- 瀏覽器視窗縮放只改變顯示比例，不改變遊戲邏輯座標或回合狀態。
- 重新整理頁面不讀取任何前一局資料，直接建立新回合。

## 網站頁面

公開遊戲頁面是單一入口，不保存遊戲資料，並且必須提供：

- 可辨識的遊戲標題與說明。
- 可取得鍵盤焦點的遊戲區或遊戲容器。
- 遊戲版面與可讀的生命／分數／結果文字。
- 不需登入即可載入的公開網址。

## 憲章合規確認

- 本資料模型的欄位意義、狀態轉換、不變條件與頁面責任均使用繁體中文；欄位名稱與事件名稱為必要程式字面值。
- 模型保留既有桌面規則，僅以瀏覽器資料型別表達相同回合狀態，不引入持久化或複雜領域層。
- 本資料模型確認符合憲章 I～VII，並支援快速驗收對初始、進行中、勝利、Game Over 與重玩的檢查。
