# 使用者介面契約：敲磚塊勝利流程

**功能規格**：[spec.md](../spec.md)

## 鍵盤輸入

| 遊戲狀態 | 輸入 | 必要結果 |
|----------|------|----------|
| 進行中、球等待發球 | Space | 依既有行為發球。 |
| 進行中、球已發出 | Left／Right 或 A／D | 在既有水平邊界內移動底板。 |
| 進行中 | Escape | 依既有行為關閉遊戲。 |
| 勝利（Won） | Space | 重置完整回合並回到全新的可遊玩狀態。 |
| 遊戲結束（Game Over） | Space | 重置完整回合並回到全新的可遊玩狀態。 |
| 勝利或遊戲結束 | 方向鍵、Escape 或其他按鍵 | 方向鍵與其他非重置按鍵不改變已結束的回合；Escape 仍可關閉遊戲。 |

## 可見狀態

### 進行中

- 版面、底板與球維持可見。
- 抬頭資訊持續顯示目前的 `Lives` 與 `Score` 數值。
- 既有的移動、碰撞、計分與生命遺失行為仍可使用。

### 勝利

- 最終版面與遊戲物件保持可見，不再進行移動或碰撞更新。
- 抬頭資訊保留最後分數與生命數。
- 畫面顯示 `You Win` 與 `Press SPACE to restart`。

### 遊戲結束

- 既有的 Game Over 顯示方式維持不變。
- 畫面持續顯示目前抬頭資訊與 `Press SPACE to restart`。

## 重置契約

從任一終止狀態按下 Space 後，下一個可見回合 MUST 顯示：

- 恢復全部 45 塊磚。
- 顯示 `Lives: 3` 與 `Score: 0`。
- 球連接在重新置中的底板上，並等待發球。
- 在新的終止結果發生前，不顯示勝利或 Game Over 訊息。
